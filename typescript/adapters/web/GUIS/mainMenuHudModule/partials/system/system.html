🤗 Comunidade, Hugging Face & Modelos Customizados (.gguf)

Modding de IA

Integração transparente com Hugging Face Hub (hf.co/) e suporte a compilação de personas e arquivos .gguf da comunidade:

🤗

1. Hugging Face Direto

Baixe qualquer modelo quantizado do HF informando o prefixo hf.co/ ou a URL do repositório.

hf.co/bartowski/Qwen2.5-1.5B-Instruct-GGUF:Q4_K_M
📁

2. Pasta Local de Mods

Coloque arquivos .gguf ou Modelfile na pasta /mods/models/ para detecção automática.

FROM ./mods/models/meu-npc-grimdark.gguf
📜

3. Criar Modelfile

Compile um novo NPC com System Prompt e temperatura embutidos via terminal Ollama ou Modelfile.

ollama create custom-npc -f ./Modelfile
