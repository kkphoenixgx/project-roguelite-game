Comandos

  • ⌨️ R / P / C / S: Alternar Ferramenta (Retângulo, Polígono, Círculo, Seleção)
  • ▭ Retângulo: Arrastar ou 2 cliques (Segure Shift para quadrado 1:1)
  • 🖱️ Esq: Selecionar / Mover Hitbox ou Ponto
  • 🖱️ Dir: Apagar Hitbox / Ponto / Cancelar
  • ⌨️ Delete / Backspace: Apagar Hitbox Selecionada
  • ⌨️ Enter: Finalizar Polígono ou Retângulo
  • ⌨️ Esc: Cancelar / Desmarcar
  • 🖱️ Scroll: Mover Verticalmente
  • Shift + Scroll: Mover Horizontalmente
  • Ctrl + Scroll: Zoom (Focado no Mouse)
  • ⌨️ Shift + Delete: Limpar Todas (Rápido)
  • ⌨️ Ctrl + Z: Desfazer (Undo)
  • ⌨️ Ctrl + Y: Refazer (Redo)
